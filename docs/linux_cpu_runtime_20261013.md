# Linux CPU运行环境与迁移验收

2026-10-13完成Linux x86_64 CPU环境安装，并通过69项代码测试及3个固定历史示例检查。它证明的是这一组工程示例在新平台上的兼容性，不是新的生物学验证、训练结果或Cell投稿准备完成。

## 可重复安装

[Linux CPU哈希锁](../requirements-runtime-linux-x86_64-py312-cpu.lock)仅记录本次实际选择的Linux CPython 3.12二进制包，不能替代其他平台的锁文件。[PyTorch官方旧版本说明](https://pytorch.org/get-started/previous-versions/)提供2.3.1的CPU发行源；[Python官方venv说明](https://docs.python.org/3.12/library/venv.html)说明隔离环境的创建方式。

本轮实际使用的是离线安装：在新venv中，针对已经核验的Linux wheel目录执行`pip install --no-index --find-links`，同时使用`--require-hashes`和上述锁文件，再运行`pip check`。完整命令、输入哈希和每一步退出码保存在本地安装记录中；源代码快照位于[迁移脚本目录](../workflows/runtime_portability_20261013/)。这些脚本需要保留的研究目录布局和原运行时制品，并非公开仓库单独即可运行的完整模型发布。

首次在lab直接下载因DNS解析失败而停止，失败日志和已创建的空环境保留。随后在能够访问官方源的电脑下载Linux包，并通过已配置的SSH传入lab；没有更改lab的DNS、代理或全局网络设置。第一次传输中断后，77/80个文件校验通过，仅补传3个缺失文件。所有80个候选包在lab校验后重新按Linux环境解析依赖，Mac专用的`appnope`未被选入最终79包锁文件。当前电脑未安装这些Linux包。
